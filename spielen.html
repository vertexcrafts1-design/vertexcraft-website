WILLKOMMEN

Dein erster Login.

Alles, was du brauchst, ist Minecraft. Du kannst mit Java oder Bedrock zu uns kommen.

JAVA EDITION

Auf dem PC

  1. Öffne Minecraft und wähle Mehrspieler.
  2. Klicke auf Server hinzufügen. Den Namen kannst du frei wählen.
  3. Trage play-vertex.com als Serveradresse ein.
  4. Speichern, verbinden und am Spawn ankommen.

BEDROCK EDITION

Handy, Tablet oder PC

  1. Gehe auf Spielen → Server → Server hinzufügen.
  2. Nutze die Adresse play-vertex.com.
  3. Den aktuell gültigen Bedrock-Port findest du in den Serverinfos auf Discord.
  4. Falls dein Gerät keine eigenen Server zulässt, melde dich im Support.
Serverinfos öffnen

So findest du dich zurecht.

01

Erst die Regeln lesen

Mit /rules siehst du die Regeln. Respektiere fremde Builds und spiele fair.

Regeln öffnen
02

Einen Platz suchen

Der RTP-NPC am Spawn bringt dich in die Welt. /claim zeigt dir die Möglichkeiten, dein Gebiet zu sichern.

Claims verstehen
03

Dein Zuhause setzen

Mit /sethome setzt du einen Home-Punkt; /home bringt dich zurück. Deine verfügbaren Slots siehst du im Spiel.

04

Leute kennenlernen

Frag im Chat oder auf Discord. Du kannst allein starten und später einem Clan beitreten.

Hilfe bekommen

Du kommst nicht drauf?

Schick uns den genauen Fehlertext und sag dazu, ob du Java oder Bedrock nutzt. Die aktuell unterstützte Version steht in unseren Serverinfos auf Discord.
