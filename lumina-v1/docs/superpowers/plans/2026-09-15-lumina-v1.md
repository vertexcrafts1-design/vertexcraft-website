# LUMINA V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native Windows LUMINA V1 Minecraft client with isolated instances, content management, Microsoft login and differentiated launcher features.

**Architecture:** A framework-neutral `Lumina.Core` owns data, filesystem operations and presets. A .NET 8 WPF `Lumina.Client` owns presentation and CmlLib integration. GitHub Actions builds and tests the Windows x64 single-file executable.

**Tech Stack:** .NET 8, WPF, CmlLib.Core 4.0.6, CmlLib.Core.Auth.Microsoft 3.3.1, xUnit.

**Spec:** `lumina-v1/docs/superpowers/specs/2026-09-15-lumina-v1-design.md`

## Global Constraints
- Windows x64 V1.
- No Python runtime or BAT file is required by users.
- User instances are isolated below `%APPDATA%/LUMINA/instances`.
- Microsoft credentials/tokens are not stored in LUMINA settings JSON.
- V1 supports Vanilla, Fabric and Quilt loaders.
- Main website branch remains untouched; work stays on `lumina-v1-client`.
